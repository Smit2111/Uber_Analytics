🚖 Uber Analytics Dashboard

An interactive and advanced Uber Ride Analytics Dashboard built using Streamlit, Pandas, and Plotly.
This project helps analyze Uber ride operations, revenue, customer ratings, cancellations, vehicle performance, and business insights through powerful visualizations.

📌 Features
📊 Dashboard
Booking Status Distribution
Ride Analytics Visualization
Interactive Charts using Plotly
📂 Dataset Explorer
View dataset overview
